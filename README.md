# Lenovo-V310-14IKB-Hackintosh
Lenovo V310 14IKB黑苹果EFI（Opencore）经本人测试 启动Big Sur无任何问题，显卡处于半残 声音炸麦 仅适合娱乐
本人配置为
CPU：i5-7200U
RAM：4GB DDR4
Harddrive：128 GB MSATA+500G SATA HDD
GPU：UHD620+R7 M340
本人从15~11挨个版本测试后BigSur是唯一正常启动的版本
Monterey直接在跑码的时候重启,Ventura内核恐慌,Sonoma依旧是跑码重启,Sequoia我不知道为什么无法启动,反正Big Sur能用就行（）
